# 发动机性能监控仿真系统

本项目是基于 C++ 和 EasyX 的 Windows 桌面仿真程序，通过图形仪表展示虚拟发动机的运行状态，支持启停控制、推力调节、故障模拟、异常报警和运行数据记录。

## 功能

- 模拟发动机停止、启动、稳定运行和停机过程。
- 展示转速、N1、排气温度、剩余燃油和燃油流量等参数。
- 在稳定运行阶段增加或减少推力。
- 模拟转速、温度和燃油传感器故障，以及低燃油、高燃油流量、超速和超温等异常。
- 根据异常情况显示报警，达到程序设定的紧急条件时自动停机。
- 将运行数据保存为 CSV 文件，将异常记录保存为日志文件。

## 开发与运行环境

- Windows。
- Visual Studio，安装“使用 C++ 的桌面开发”工作负载。
- MSVC v143 C++ 工具集和 Windows SDK，工程目标版本为 10.0。
- 安装到对应 Visual Studio 环境的 EasyX 图形库，并支持所选编译平台。

当前工程采用 Visual Studio 2022 格式，提供 Debug、Release 及 x64、Win32 配置。建议首次使用 Debug / x64，与原项目已有程序的构建配置保持一致。

## 编译与启动

1. 准备上述开发环境并安装 EasyX。
2. 使用 Visual Studio 打开仓库根目录下的 `Project2.sln`。
3. 在工具栏选择 `Debug` 和 `x64`。
4. 在“生成”菜单中选择“生成解决方案”。
5. 生成成功后，在“调试”菜单中选择“开始执行（不调试）”，或按 `Ctrl + F5`。

默认生成的程序路径为 `x64/Debug/Project2.exe`。也可以在生成成功后从文件资源管理器打开该程序。

如果提示找不到 `graphics.h`，请检查 EasyX 是否已安装到当前使用的 Visual Studio 环境。如果提示缺少 v143 工具集或 Windows SDK，请通过 Visual Studio Installer 补充相应组件。

## 操作方法

1. 点击 `START` 启动虚拟发动机，观察仪表参数变化。
2. 发动机进入稳定运行后，使用 `Thrust+/-` 调节推力。
3. 使用界面上的故障按钮观察异常报警。启动阶段超温测试需要在启动过程中触发，稳定运行阶段超温测试需要在稳定运行时触发。
4. 点击 `STOP` 执行停机。
5. 按 `ESC` 退出。如果图形窗口中按键没有响应，请切换到程序的控制台窗口后按 `ESC`。

程序在当前工作目录下自动创建 `logs` 文件夹，输出 `excal_时间戳.csv` 和 `log_时间戳.log`。运行位置需要具备写入权限。
